        Polylines Sankey

        An interactive version of the Sankey ribbons in R/functions.R. It reads the same inputs as sankey_ribbons() / sankey_ribbons_graph(), saved as CSV files.

        Files

        • Flow matrices: one numeric CSV per stage (rows = source nodes, columns = target nodes); adjacent stages must share dimensions. In graph mode, one square matrix over all loc rows. Headers and row names (as written by R's write.csv()) are detected and used as node names.
        • Node locations (loc): columns set, node, x, y plus optional width, label, cex, font, height, color and merge_col. A headerless file is read like R's numeric loc matrix (set, node, x, y [, width [, height]]).
        • Strand / mid colors: color matrices shaped like the flow matrices (hex such as #5B8CBAAA, CSS names, R grayNN, or NA).
        • Project: a .json file exported from this app restores everything.

        Drop files anywhere, or use Open files…; file roles are detected from their contents and names (files whose names contain “mid” are mid colors). Stage order follows file names; reorder with the arrows.

        Interaction

        • Hover strands or nodes for values and shares; click to edit them in the inspector.
        • Drag nodes to move them (Shift: vertical only, Alt: horizontal only).
        • Drag a strand up or down to reorder it within the stack at its nearer end.
        • Ctrl/⌘+Z and Ctrl/⌘+Shift+Z undo and redo; F fits the view; Esc clears the selection.

        Export → R bundle writes the CSVs, a loc.csv with your edits and a sankey.R script that redraws the plot with the R functions.
